# 業務ナレッジ収集アシスタント

Google Apps Scriptで動作する、業務手順や対応事例を対話形式で記録するWebアプリです。

業務名、作業手順、判断基準・注意点を順番に入力すると、対話ログとともにGoogleスプレッドシートへ保存します。複数の業務を続けて入力することもできます。

## 機能

- Google Apps ScriptのWebアプリとして動作
- 業務名、手順、注意点を段階的にヒアリング
- 複数の業務・対応事例を1回のセッションで追加
- 入力した対話ログを含めてスプレッドシートへ保存
- 保存済みスプレッドシートを画面から開く
- スプレッドシートに担当者のメールアドレスと登録日時を記録

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.js` | Webアプリの表示、スプレッドシート参照、ナレッジ保存 |
| `Index.html` | 対話画面、入力ステップ、保存処理 |
| `appsscript.json` | GASのランタイム、権限、Webアプリ設定 |
| `.clasp.json` | claspとApps Scriptプロジェクトの紐付け |

## 前提条件

- Googleアカウント
- Google Apps Scriptプロジェクトを操作できる権限
- 保存先のGoogleスプレッドシートに紐づいたApps Scriptプロジェクト
- Node.jsとclasp（ローカルから同期する場合）

claspは次のコマンドでインストールできます。

```bash
npm install -g @google/clasp
```

## セットアップ

1. リポジトリを取得します。

```bash
git clone https://github.com/aosakabe-lang/nippo-gas-project.git
cd nippo-gas-project
```

2. claspへログインします。

```bash
clasp login
```

3. `.clasp.json` の `scriptId` が対象のApps Scriptプロジェクトを指していることを確認します。

4. GASプロジェクトの最新コードを取得、またはローカル変更をアップロードします。

```bash
clasp pull
# ローカルからGASへ反映する場合
clasp push
```

5. Apps Scriptのデプロイ画面からWebアプリとしてデプロイします。

## 使い方

1. Webアプリを開きます。
2. 記録したい業務名を入力して送信します。
3. 作業手順を入力して送信します。
4. 判断基準や注意点を入力して送信します。「なし」も入力できます。
5. 「今日の日報保存」を押して保存します。
6. 別の業務を記録する場合は、「別の業務を追加」を押して同じ手順を繰り返します。
7. 「シートを確認」から保存先スプレッドシートを開きます。

## スプレッドシートへの保存

`Code.js`は、現在のスプレッドシートに`業務ナレッジデータ`シートを作成して使用します。シートが存在しない場合、次のヘッダーが自動作成されます。

```text
登録日時 | 担当者 | 対象業務名 | 作業手順 | 判断基準・注意点 | 対話ログ全文 | ステータス
```

保存時のステータスは`未整理（マニュアルの種）`です。保存に成功すると、シートのURLが画面に表示されます。

## Webアプリ設定

`appsscript.json`では、次の設定になっています。

- タイムゾーン: `Asia/Tokyo`
- ランタイム: `V8`
- 実行ユーザー: デプロイしたユーザー
- アクセス: 自分のみ

利用者を増やす場合は、Apps Scriptのデプロイ画面でアクセス権を変更し、保存先スプレッドシートへの権限も確認してください。

## セキュリティに関する注意

- 保存される対話ログには業務情報や個人情報が含まれる可能性があります。スプレッドシートの共有範囲を適切に設定してください。
- `Session.getActiveUser().getEmail()`で担当者のメールアドレスを記録します。実行ユーザーやアクセス設定によっては匿名ユーザーとして記録されます。
- `Code.js`にはAPIキーや固定のスプレッドシートIDを設定していません。現在の実装では、GASに紐づいたアクティブなスプレッドシートを使用します。
- Webアプリのアクセス権を変更する場合は、意図しないユーザーが業務情報を閲覧・登録できないか確認してください。
